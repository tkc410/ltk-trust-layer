STYLE FOR EVERY IMAGE
- Photorealistic lifestyle photo, vertical 4:5 (1024x1280).
- Natural daylight, warm and candid, clean home, cafe or street settings.
- The product is the clear hero of the frame.
- When a person appears, show them from the neck down, or from behind, or only hands. No faces.
- No text, no captions, no watermarks, no logos, no brand names, no real or famous people.

HOW TO DELIVER
- Generate in batches of 5. After each batch, wait for me to say "next".
- Name each image exactly as listed (for example p004.jpg).
- When all 40 are done, use Python to put every image, with these exact file names, into one file called ltk_posts.zip and give me the download link.
- If you cannot make a zip, give me each image with its file name so I can save it myself.
